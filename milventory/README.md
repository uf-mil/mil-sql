# Milventory - Robotics Room Inventory Management

A React application for managing inventory in a robotics room with a zoomable map interface.

## Features

- Interactive zoomable and pannable map
- Drag and drop items between containers
- Shift-click multi-select
- Edit items with quantity and description
- Add new items via modal
- Resizable panels
- Tooltips on hover

## Installation

```bash
npm install
```

## Running

```bash
npm start
```

The app will open at [http://localhost:3000](http://localhost:3000)

## Building

```bash
npm run build
```

## Technologies

- React 18
- D3.js 7 (for zoom/pan functionality)
- CSS Variables for theming
